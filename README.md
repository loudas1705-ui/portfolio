# portfolio

A modern, responsive personal portfolio website showcasing web design projects, technical skills, and digital services.

## About the Project

This portfolio was created to present my work, demonstrate my technical abilities, and provide potential clients with an easy way to explore my projects and request services.

The website features a clean, editorial-inspired design with an asymmetrical project gallery, carefully structured layouts, and responsive pages.

## Design & Visual Identity

- **Style:** Modern, Minimalist & Editorial
- **Primary colors:** Charcoal, Light Grey & Warm Grey
- **Typography:** DM Sans & Manrope
- **Layout:** Clean compositions with asymmetrical project presentations
- **Responsive design:** Desktop, tablet and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

### 1. Download or Clone the Project

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Open the Project

Open the project folder in Visual Studio Code or another code editor.

### 3. Run the Website

Open `index.html` in your browser.

For a better development experience, you can use the Live Server extension in Visual Studio Code.

## Contact Form

The contact form uses EmailJS to handle message submissions.

To configure it, add your EmailJS credentials to the appropriate JavaScript configuration:

- Service ID
- Template ID
- Public Key

Do not expose private credentials or sensitive account information.

## Customization

You can customize the website by editing:

- `index.html` — Homepage content
- HTML page files — Individual page content
- `style.css` — Colors, typography, layouts and responsive styles
- `main.js` — Interactive functionality
- `assets/images/` — Project images and visual assets
